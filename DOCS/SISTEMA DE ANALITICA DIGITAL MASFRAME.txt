# ⭐ **DOC-AD01 — Sistema de Analítica Digital MAS@FRAME®**  
*(Documento oficial del Sistema Documental MAS@FRAME®)*

## **1. Propósito del Sistema de Analítica Digital**  
El Sistema de Analítica Digital MAS@FRAME® permite medir, analizar y optimizar el rendimiento digital del método, garantizando trazabilidad completa desde la visita web hasta el pago del cliente.

Su objetivo es:

- medir el comportamiento real de los usuarios,  
- identificar cuellos de botella,  
- optimizar la captación,  
- mejorar la conversión del ESE,  
- aumentar diagnósticos agendados,  
- aumentar ventas,  
- alimentar el Sistema de Calidad con datos digitales.

---

## **2. Herramientas oficiales del sistema**  
El sistema utiliza dos herramientas gratuitas y obligatorias:

### **2.1. Google Analytics 4 (GA4)**  
Herramienta oficial para medir:

- tráfico  
- fuentes  
- comportamiento  
- eventos  
- conversiones  
- funnels  
- campañas  

### **2.2. Microsoft Clarity**  
Herramienta oficial para medir:

- mapas de calor  
- grabaciones de sesiones  
- clics  
- scroll  
- abandono  
- fricción  

Ambas herramientas son obligatorias para cualquier web que utilice MAS@FRAME®.

---

## **3. Eventos oficiales MAS@FRAME® (GA4)**  
Los siguientes eventos son **obligatorios** y deben configurarse exactamente con estos nombres:

1. **ESE_iniciado**  
   Se dispara cuando el usuario abre o inicia el ESE.

2. **ESE_completado**  
   Se dispara cuando el usuario finaliza el ESE.

3. **Lead_generado**  
   Se dispara cuando el usuario envía un formulario de contacto.

4. **Diagnostico_agendado**  
   Se dispara cuando el usuario reserva una cita.

5. **Pago_realizado**  
   Se dispara cuando el usuario completa un pago.

Estos eventos forman la base del funnel digital MAS@FRAME®.

---

## **4. Funnel Digital MAS@FRAME®**  
El funnel oficial que debe configurarse en GA4 es:

1. **Visita web**  
2. **ESE_iniciado**  
3. **ESE_completado**  
4. **Lead_generado**  
5. **Diagnostico_agendado**  
6. **Pago_realizado**

Este funnel es obligatorio para:

- medir la eficacia de la web,  
- medir la eficacia del ESE,  
- medir la eficacia comercial,  
- medir la eficacia de campañas,  
- detectar fugas,  
- optimizar conversión.

---

## **5. Configuración técnica obligatoria**

### **5.1. Instalación de GA4**  
- Insertar el script de GA4 en el `<head>` de todas las páginas.  
- Activar medición mejorada.  
- Crear los 5 eventos oficiales.  
- Marcar como conversiones:  
  - `ESE_completado`  
  - `Lead_generado`  
  - `Pago_realizado`

### **5.2. Instalación de Microsoft Clarity**  
- Insertar el script en el `<head>` de todas las páginas.  
- Activar mapas de calor.  
- Activar grabaciones.  
- Activar detección de fricción.
