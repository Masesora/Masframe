MINIVÍDEOS VERTICALES · MASESORA®
==================================

Especificaciones técnicas
--------------------------
Formato       : MP4 (H.264) · MOV para edición
Resolución    : 1080 × 1920 px (9:16)
Fotogramas    : 25 fps
Duración      : 15s / 30s / 60s según plataforma
Audio         : AAC 44.1kHz estéreo (si aplica)
Peso máximo   : 50 MB (Instagram/TikTok) · 512 MB (LinkedIn)

Plataformas destino
--------------------
Instagram Reels  : 1080×1920 · máx 90s · MP4
TikTok           : 1080×1920 · máx 60s (recomendado) · MP4
LinkedIn         : 1080×1920 o 1080×1080 · máx 10min · MP4
WhatsApp Status  : 1080×1920 · máx 30s · MP4

Convención de nombres
----------------------
YYYYMMDD_masesora_[tema]_[duración]s_v[n].mp4
Ejemplo: 20260626_masesora_masframe_30s_v1.mp4

Zona segura
------------
Mantener texto e iconos entre px 150 y px 1770 vertical
(evitar zona inferior 150px — iconos UI de plataformas)

Paleta de color
----------------
Navy   #0F1A35
Gold   #B89D52
Cream  #F9F7F2

Fuente en vídeo
----------------
Montserrat 900 para títulos · Tamaño mínimo en pantalla: 40px

Archivos fuente (para edición)
--------------------------------
Depositar aquí los proyectos .prproj (Premiere) / .aep (After Effects)
o .capcut con todos los assets vinculados.
