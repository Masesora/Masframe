Cómo instalarla

✉ Gmail
  1. 1 ⚙ Configuración → Ver toda la configuración
  2. 2 Pestaña "General" → sección "Firma" → Nueva
  3. 3 En el editor: clic <> → pega el código HTML
  4. 4 Asigna como predeterminada → Guardar
📧 Outlook
  1. 1 Archivo → Opciones → Correo → Firmas
  2. 2 Nueva → nombre "MASESORA"
  3. 3 Editor → modo HTML → pega el código
  4. 4 Asigna como predeterminada → Aceptar
Atajo Gmail (sin HTML): Abre este archivo en el navegador → selecciona la firma entera de la vista previa → Ctrl+C → pégala directamente en el editor de firma de Gmail.

⚠ Foto: Para que aparezca en emails, la imagen de Maite debe estar alojada en un servidor. Sustituye la ruta src="..." por la URL pública de la foto en masesora.com.
